Quick Installation Guide

How to install or update ZGE Geodetic Suite on your Windows workstation.

STEP 01

Download Release ZIP

Click Download Latest Build above to get the official encrypted client package from GitHub Releases.

STEP 02

Extract to Local Drive

Extract the archive to a permanent folder such as C:\ZGE_Suite.

STEP 03

Load in AutoCAD

Run the included loader or use NETLOAD / APPLOAD inside AutoCAD to initialize the ZGE Geodetic Suite ribbon.

STEP 04

Activate Once

Paste your ZGE-XXXX-XXXX-XXXX license key when prompted. Future updates on the same PC recognize your license automatically.
